# 🕊️ II Foro Internacional de Paz Granada 2025

**Fundación Unamos Culturas - Sitio Web Oficial**

## 📋 Descripción del Proyecto

Sitio web moderno, responsivo e interactivo para el **II Foro Internacional de Paz Granada 2025**, organizado por la Fundación Unamos Culturas. El evento se realizará del 20-25 de octubre de 2025 bajo el tema **"Violencia y Paz: Tensiones y Oportunidades hacia una Humanidad Común"**.

### 🎯 Características Principales

#### **Diseño y Experiencia de Usuario**
- **Diseño moderno**: Estética limpia, minimalista y profesional
- **Paleta de colores oficial**: 
  - 🔴 Rojo (#e53e3e) - Ciencia
  - 🔵 Azul (#3182ce) - Arte  
  - 🟢 Verde (#38a169) - Cultura
  - 🟣 Púrpura (#9f7aea) - Memoria de pueblos originarios
- **Tipografía**: Inter (Google Fonts) con jerarquías claras
- **Responsivo**: Diseño mobile-first compatible con todos los dispositivos
- **Iconografía**: Font Awesome para representación visual intuitiva

#### **Funcionalidades Interactivas**
- **Navegación fija**: Header con efecto blur que permanece visible
- **Smooth scrolling**: Transiciones suaves entre secciones
- **Modales dinámicos**: Detalles completos del programa diario
- **Galería interactiva**: Carrusel Swiper.js con navegación
- **Animaciones sutiles**: Efectos AOS.js y CSS para mejor UX
- **Formularios responsivos**: Contacto y suscripción con feedback visual

## 🚀 Instalación y Configuración

### **Opción 1: Servidor Local Simple**
```bash
# Clona el repositorio
git clone [url-repositorio]
cd foro-paz-granada-2025

# Inicia servidor local (Python)
python3 -m http.server 8000

# O con Node.js
npx serve .

# O con PHP
php -S localhost:8000
```

### **Opción 2: Live Server (VS Code)**
1. Instala la extensión "Live Server" en VS Code
2. Abre el proyecto en VS Code
3. Click derecho en `index.html` → "Open with Live Server"

### **Personalización de Contenido**

#### **Actualizar Información del Evento**
